Open External Validation Pack for Structural Stability and Recovery Models

Wang, Youfu

2026-06-09 | Other | DOI: 10.5281/zenodo.20606790

Abstract / source description

This package is an open request for external validation of several structural stability and recovery modeling directions. The materials are intentionally non-confidential and do not disclose private patent drafts, unpublished implementation details, personal chat records, or internal notes. The current evidence boundary is explicit: CSA-style condition-space replay has produced interpretable warning behavior in public-data experiments, but it has not yet demonstrated incremental predictive value over optimized dominant single-component baselines such as q95-only or plasma-current-only in locked replay settings. Therefore, this package does not claim validation. It invites independent groups to test narrower, falsifiable validation cards. The public validation cards include CLM-DIII-D topology-plus-phase validation, SCCD component-dominance validation, photonic quantum chip stability classification, PSL slow-light / near-edge stability-window validation, and Residual Flow simulation replication.
