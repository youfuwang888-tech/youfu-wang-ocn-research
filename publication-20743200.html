Graph-SERO: A Temporal Graph Dynamics Replay Protocol for Event-Relative Tokamak Disruption Early-Warning Validation

Wang, Youfu

2026-06-18 | Publication | DOI: 10.5281/zenodo.20743200

Abstract / source description

This technical report presents Graph-SERO, a proposed temporal graph dynamics framework and replay protocol for event-relative tokamak disruption early-warning validation. The framework represents diagnostic channels as an evolving graph A(t), defines structural drift Delta A(t) and structural acceleration S(t), and specifies a claim-bounded validation workflow based on manifest locking, event-time provenance, baseline comparison, false-alarm retention, and held-out replay. This release is a preregistration-style protocol and paper draft. It does not report completed EAST, JET, MAST-U, or DIII-D validation results, and it should not be cited as evidence that Graph-SERO outperforms existing disruption predictors. The purpose of the release is to enable transparent review, data-access discussion, and external collaboration on a reproducible replay package.
