Core Compression Map for Collective Excitation Systems

Wang, Youfu

Publication date: 2026-03-10 | DOI: 10.5281/zenodo.18933489

Other public research records

Abstract

Description &nbsp; This work introduces a structural framework called the Core Compression Map, designed to compare collective excitation phenomena across different physical systems. &nbsp; Many systems approaching dispersion boundaries exhibit similar structural behaviors, including reduced group velocity, dispersion flattening, and hybrid mode formation. Examples include slow light in photonic crystal waveguides, phonon dispersion flattening in crystalline lattices, and exciton&ndash;polariton hybridization in semiconductor microcavities. &nbsp; The proposed framework represents these systems within a common phase diagram defined by the coordinates &nbsp; (\mathcal J,\Delta_{\text{stab}}) &nbsp; where \mathcal J represents compression strength and \Delta_{\text{stab}} denotes stability margin. &nbsp; Within this representation four structural regimes emerge: &nbsp; geometry basin (G) gap ridge (B) resonance wall (R) exit zone (X) &nbsp; &nbsp; Three representative systems serve as standard windows anchoring the structural trajectory &nbsp; G \rightarrow B \rightarrow R \rightarrow X. &nbsp; The Core Compression Map provides a structural representation that may help compare collective excitation phenomena across photonic, phononic, and polaritonic systems. &nbsp; This work is intended as a conceptual framework rather than a replacement for existing microscopic theories.
